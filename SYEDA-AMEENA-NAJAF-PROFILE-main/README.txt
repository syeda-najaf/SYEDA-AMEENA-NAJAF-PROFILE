# Syeda Ameena Najaf Portfolio

## Run in VS Code

1. Open this folder in VS Code.
2. Put your real CV at:
   `assets/resume.pdf`
3. Open `script.js`.
4. Replace:
   `YOUR_EMAIL@example.com`
   with your real email address.
5. Add certificate images under:
   `assets/certificates/`
6. In `script.js`, replace the five certificate placeholder entries with your exact CV certificate names and image paths.
7. Open `index.html` with the VS Code Live Server extension.

## Files

- `index.html` = page structure
- `style.css` = responsive design
- `script.js` = interactions, project data, filters, modals, navigation and contact form

## Important

The portfolio uses no framework and no npm setup. It runs as a normal browser website.

For deployment, upload the folder to GitHub and connect the repository to Vercel.
